SMART PRICE OFFER
=================


מטרת הפרויקט
------------

מערכת להפקת הצעות מחיר ללקוחות בינלאומיים על עגורני צריח.
ממלאים טופס מלא עם מפרט טכני, מחירים ותנאי תשלום, ומקבלים הצעה מעוצבת לייצוא כקובץ פי די אף.


סטטוס
-----

פעיל ועובד. כולל:

טופס מלא של פרטי לקוח, מפרט טכני שכולל מספר יצרן, כננות, מצב, הערות, מחירים, והוצאות אחרות.

תצוגה מקדימה חיה.

ייצוא ל פי די אף.

חישוב סכומים אוטומטי. הסדר: סכום ביניים פחות הנחה, פלוס הוצאות אחרות, פלוס הובלה, פלוס מע"מ על הכל.

תמיכה בעברית ובאנגלית.

שדה הוצאות אחרות דינמי כמו צביעה, שיפוץ, חלקי חילוף וכו'. כל הוצאה מתווספת לסכום הסופי.

אופציה חדשה באינקוטרמס בשם AS IS, לסחורה ממרכז לוגיסטי.


איך מריצים
----------

1. דאבל קליק על קובץ ההפעלה start.bat בתיקיית הפרויקט.
2. החלון השחור של השרת ייפתח, משאירים אותו פתוח.
3. הדפדפן ייפתח אוטומטית בכתובת המקומית:

http://localhost:5173/SMART-PRICE-OFFER/

4. ממלאים את הטופס.
5. לוחצים על תצוגת הצעה כדי לראות אותה.
6. או לוחצים על ייצוא פי די אף כדי להוריד.

חוקי עבודה על הפרויקט הזה
--------------------------

1. אסור לשנות את קובץ מבנה הנתונים types.ts בלי אישור מפורש שלי. כל שינוי שם משפיע על כל החלקים של האפליקציה.

2. הקבצים העיקריים של הפרויקט יושבים בתת תיקייה של רכיבים. כל שינוי שם דורש בדיקה שהאפליקציה מתקמפלת תקין.

3. תמיד תתייחס לקובץ ההיכרות שבתיקייה של קלוד קוורק בדרייב כדי לדעת את הסטנדרטים שלי לעבודה.
